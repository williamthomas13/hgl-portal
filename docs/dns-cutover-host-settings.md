# DNS cutover — host-sensitive settings for the domain pair (PL-474, Sep 21 2026 · revised by PL-498, Sep 23)

**Decision (Scarlett, Sep 23 — revises Sep 21):** `portal.highergroundlearning.com` = canonical for **everything** the app serves — every signed-in surface, every emailed link, AND the public pages (`/classes`, `/team`, `/inquire`, `/compass`, `/partner`, `/{code}`, `/{code}/register`, `/c/{slug}`, the embeds) · `hgl.co` / `www.hgl.co` = a **pure redirector**: every path 301s (public GET) / 308s (signed-in, tokenized, non-GET) to the same path + query on the portal host; the bare root 301s to the main site; paths the portal has no route for still end on `https://www.highergroundlearning.com/{path}` (the standing wildcard — now two permanent hops, hgl.co → portal → main site). Nothing is ever *served* on hgl.co. `highergroundlearning.com` stays Squarespace; its own `/classes` and `/team` become Squarespace URL mappings (301) to the portal host at row 20. Why: hgl.co has no domain history — a public home there would split the brand across two domains for search + LLM entity resolution, and every link accrued there would migrate twice once the marketing site moves to the apex (after the Synap replacement). Printed codes keep working because `hgl.co/{code}` redirects. One deployment serves both hosts. This table **replaces sections 2–4 of the DNS runbook** — Scarlett + Claude tick it through; Code touches none of it (no DNS, no Vercel domains, no env vars).

How the pair stays honest in code (PL-474 → PL-498): `proxy.ts` redirects **every** hgl.co path to the portal host (catch-all matcher; 301 for public GETs, 308 for `PORTAL_ONLY_PATH_PREFIXES` and any non-GET; `/` → 301 main site); the portal host is never redirected (no loop); canonical / OG / sitemap / JSON-LD / llms.txt / embed links use `publicSiteOrigin()` = `emailBaseUrl()` = `PRODUCTION_BASE_URL` (the portal host — `PUBLIC_SHORT_ORIGIN` is retired and ignored if set); the JSON-LD `Organization` carries `url` = the portal host and `sameAs` = the brand domain; the origin guard treats `hgl.co` as production with or without `ADDITIONAL_PRODUCTION_HOSTS`. Gate: `node scripts/regress-canonical-hosts.mjs http://localhost:3100`.
