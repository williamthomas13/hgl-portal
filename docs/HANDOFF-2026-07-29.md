## Techniques & gotchas (hard-won this session)

- **Turbopack does NOT hot-reload API-route edits** — restart the dev server (`preview_start {name:"dev"}`) before route E2Es. Client components HMR fine.
- **The browser tab randomly drifts to https://highergroundlearning.com mid-automation** (hit 3× in one session) — re-navigate to localhost and prefer single-shot scripts over multi-step page state.
- Magic-link auth: `node scripts/.tmp-magiclink.mjs` prints an /auth/confirm URL (swap `next=`).
- Compile-and-call harnesses: build INSIDE the repo (`scripts/.tmp-build-*`), outDir is FLAT (require `email.js`, not `app/utils/email.js`). Monkey-patch compiled CJS exports (sendOnce, gcal) BEFORE requiring dependents.
- Supabase Management API via `/usr/bin/curl` (plain `curl` may be missing from PATH); use `$q$…$q$` dollar-quoting to dodge shell-apostrophe hell; the auto-mode classifier sometimes blocks UPDATE/DELETE through curl — a small supabase-js node script (the same shape as harness cleanups) is the accepted path.
- `duration_minutes` on tutoring_sessions is a GENERATED column — never insert it.
- `regress:mutation-buttons` audits that busy flags reset ONLY in a `finally` — handle post-response prompts (e.g. overdraw confirm) AFTER the finally, never mid-try.
- JSX eats inline-boundary spaces — `{' '}` (PL-119, bit again in batch 20).
- SearchCombobox options fire on MOUSEDOWN — programmatic `.click()` is a no-op.
